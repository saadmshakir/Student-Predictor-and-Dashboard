# Student Predictor and Dashboard

A modern, intuitive web application designed to help students track their academic progress, manage daily course schedules, and view up-to-date grades in one centralized location.

## 🚀 Features
* **Grade Tracker:** Visual data summaries of current semester grades and cumulative GPA.
* **Course Schedule:** An interactive calendar showing daily class times and locations.
* **Task Manager:** A built-in to-do list for tracking homework assignments and upcoming exams.
* **Profile Management:** A dedicated settings page to update student contact details and preferences.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript (ES6)
* **Styling Framework:** Bootstrap 5 / Tailwind CSS (Optional: change to match yours)
* **Backend/Storage:** LocalStorage / Firebase (Optional: change to match yours)
